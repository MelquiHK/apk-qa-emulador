# apk-qa-emulador

Emulador de Android en la nube pa probar los APK de Mel sin depender de una maquina local con KVM: GitHub Actions arranca un emulador con aceleracion por hardware, instala el APK indicado, lo abre y devuelve capturas de pantalla y el logcat como artefacto de la corrida.

Uso: pestana **Actions** -> **Probar APK en emulador** -> **Run workflow** (url del APK + paquete + actividad). Tambien se puede disparar por API.

Creado por Kenop (asistente de Mel) el 2026-11-13 bajo la autorizacion permanente de Mel del 2026-10-29 de elegir la via de prueba de apps, incluido emulador en la nube.
